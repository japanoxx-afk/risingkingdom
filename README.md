# Rising Kingdoms 한글패치 런처

Windows용 한글패치 설치·백업·복원 런처와 게임 리소스 조사 도구입니다.

**현재 상태: 런처 구현 / 전체 한글 번역 패키지 미완성.** 현재 실행 파일만으로 게임이 한글화되지는 않습니다. 번역이 없는 상태에서 적용 성공으로 표시하지 않습니다.

## 실행

1. `Launch.cmd`를 더블클릭합니다. 첫 실행 때 자동으로 빌드합니다. 또는 PowerShell에서 `./build.ps1`을 실행합니다. Windows 기본 .NET Framework C# 컴파일러를 사용하며 추가 패키지가 필요하지 않습니다.
2. `build/RisingKingdomsKO.exe`를 실행합니다.
3. 기본 게임 경로는 `C:\Program Files (x86)\Steam\steamapps\common\Rising Kingdoms`입니다.
4. **설치본 조사**로 로컬 번역 카탈로그를 추출합니다. 게임 파일은 변경하지 않습니다.
5. 전체 번역·한글 글꼴 검증이 끝난 패키지 폴더를 선택한 다음 **한글패치 적용**을 누릅니다. 패키지가 없으면 적용을 거부합니다.
6. **원본 복원**으로 해당 설치본의 원본을 복구합니다. 쓰기 권한이 부족하면 관리자 권한으로 실행합니다.

## 실제 설치본 조사 결과

2026-10-25 설치본에서 직접 확인했습니다.

| 리소스 | 내부 파일 수 | 확인 내용 |
| --- | ---: | --- |
| `Packs/data.pak` | 2,969 | 텍스트 리소스에 `[[숫자ID]]영문[[]]` 표식 4,821개 |
| `Packs/assets.pak` | 7,117 | 이미지 등 리소스. 위 텍스트 표식 없음 |
| `Local/english.pak` | 299 | 주로 영어 음성. 텍스트 표식 없음 |
| `adventures/*.bfhp` | 4 | 세 종족 캠페인 및 튜토리얼. 내부 포맷 추가 분석 필요 |
| `Local/Fonts/*.apf` | 6 | 기존 글꼴의 한글 렌더링 미검증. INI 범위에는 한글 음절 없음 |

4,821은 PAK에서 추출한 표식의 **출현 횟수**이며 고유 ID는 2,571개입니다. 전체 게임 문자열 수나 전체 번역률은 아닙니다. 카탈로그에는 중복 ID와 원문이 포함됩니다. 캠페인, 튜토리얼, 이미지 속 글자, 실행 파일에 내장된 글자까지 조사해야 전체 범위를 확정할 수 있습니다.

## 전체 한글화를 위해 남은 작업

- 전체 텍스트 범위 확정 및 캠페인 BFHP 텍스트 추출.
- 문맥·용어를 통일한 한국어 번역과 자리표시자 검증.
- 엔진의 문자열 인코딩 및 ID 조회 방식 확인.
- 한글을 표시할 APF 글꼴 생성 또는 글꼴 렌더러 호환성 해결.
- 패치된 PAK 재구성과 캠페인 반영 방식 검증.
- 실제 게임에서 메뉴·세 종족 캠페인·튜토리얼·설명문 표시 검수.

원본 게임 리소스나 추출한 전체 영문은 저장소에 포함하지 않습니다. `reports/`는 설치된 게임에서 로컬로 생성되며 Git에서 제외합니다.

## 안전 동작

- 모든 패치 파일과 원본의 SHA-256을 확인한 뒤 백업합니다.
- 모든 원본의 백업이 끝난 뒤 파일별로 원자적 교체를 수행합니다.
- 중단되면 게임 폴더의 `.risingkingdom-ko/backup.json`으로 복원을 재시도할 수 있습니다. 적용 중단 상태에서는 런처의 게임 실행을 막습니다.
- 기존 패치 기록이 있으면 재적용을 막고 원본 복원을 안내합니다.
- 게임 업데이트 등으로 파일이 예상 밖으로 바뀌면 덮어쓰지 않고 복원을 중단합니다.
- 복원 후 백업은 게임 폴더의 `.risingkingdom-ko-backup-*`에 보관합니다.
- 자동 다운로드, 관리자 권한 자동 요청, 원본 EXE 수정은 하지 않습니다.

## 명령행 검사

```powershell
./build.ps1
$process = Start-Process ./build/RisingKingdomsKO.exe -ArgumentList '--self-test' -Wait -PassThru
if ($process.ExitCode -ne 0) { throw 'Self test failed' }
./build/RisingKingdomsKO.exe --inspect 'C:\Program Files (x86)\Steam\steamapps\common\Rising Kingdoms' ./reports
```

자체 테스트는 임시 게임 폴더에서 설치·복원·중단 복구·경로 이탈 차단·미완성 패키지 거부·손상 감지·외부 변경 보존을 확인합니다. 실제 게임 화면의 한글 렌더링 검증을 대신하지 않습니다.

패키지 형식은 [docs/package-format.md](docs/package-format.md)를 참고하세요.
